# Godot W7 体验收敛与保存失败路径

> 2026-10-21 · P3 子任务 · 父任务 `10-18-godot-playable-slice`。
> 依据：[实现重设计 W7](../../10-18-godot-impl-redesign/implement.md)、[验证矩阵 V12](../../10-18-godot-impl-redesign/validation.md)。

## 目标

在不改规则与内容的前提下，收敛真实桌面试玩的可读性、键盘闭环、长文/缩放和
保存失败恢复；把“保存失败后还能重试、不会静默丢进度”做成可测行为。

## 需求

- 720p/1080p：事件长文不得把选项/关闭按钮挤出视口；超长正文可滚动。
- 键盘：焦点环可见；Tab 不逃出当前模态；模态关闭后焦点回到触发控件或稳定
  日常行动；Esc 顺序与现有优先级一致。
- 保存失败：暂停页显示失败原因与“重试保存”；保存并返回/退出只有在保存成功
  后才离开；失败时玩家留在游戏内，快照保留可重试。
- 未保存退出：标题页退出在保存失败时给出二次确认，不静默丢进度。
- 连点/失焦/暂停：沿用 W5 输入韧性；本任务补保存失败与焦点路径。
- 证据：实际窗口检查表 + 结构化试玩记录（≥3 人或明示限制）。

## 验收

| ID | 结果 |
| --- | --- |
| W7-A | 保存失败不离开游戏，重试成功后保存并返回/继续可用 |
| W7-B | 失败快照保留，不在失败时重放动作/重复扣款 |
| W7-C | 长事件正文在 720p 下可滚动，选项与关闭按钮始终可达 |
| W7-D | Tab/Enter/Esc 在暂停、事件、蛊、战斗、日结、结局中不越界 |
| W7-E | 720p/1080p 窗口检查与试玩记录落盘，未测项明示（真人记录待补） |

规则/内容/平衡改动、V2 策略、正式美术、W8 桌面包/Web 验收。
