# P4 执行清单

## 依赖门槛

P3的V2可玩闭环/节奏实验和候选版本冻结，确认测试与产物环境。按 [W8](../10-18-godot-architecture-plan/implement.md) 及 [验证矩阵](../10-18-godot-architecture-plan/validation.md)，审核本任务artifacts后启动。

## 顺序

1. 记录版本/环境，复核 P1–P3 证据，建立 AC1–AC10 矩阵。
2. 运行规则、跨引擎、存档与旧版回归，修复或明确归类已知旧 E2E 问题。
3. 用调参前登记、候选冻结后首次运行的新V2保留集评估，保存原始结果/失败/参数及后段重复度；不将旧V1保留集称未见数据。
4. 实机真实输入完成两策略及失败恢复，检查中文/缩放/风险提示。
5. 导出本机桌面包并解压重跑；验证 Web 或给阻断复现步骤。
6. 完善当前 README / IMPLEMENTATION / VERIFICATION 和本地试玩说明。
7. 输出报告、包路径、校验值与继续/回退建议，父任务做最终评审。

## 验证与回退

已有 `npm run check` / `npm run test:e2e`；新增的模拟/对照/Godot runner 使用 P2 固化入口。规则或内容变化需要重新冻结再跑保留集，不能不标版本混合统计。

粗估 3–5 开发人日。只产出本地包，不自动上传或发布。阶段失败按发现回到对应任务，保留证据，不以删失败用例过验收。
