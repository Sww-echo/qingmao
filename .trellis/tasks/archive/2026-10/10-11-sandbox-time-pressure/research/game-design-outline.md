# 青茅山：生存沙盒设计大纲

版本：v0.5（设计稿，未实现）
日期：2026-10-10
定位：本文是后续章节与整体玩法的总纲，约束「怎么改现有第一章」和「青茅山篇怎么分段」。

---

## 〇、一句话定位

**你不是在重演方源的路，而是在方源的处境里，用方源能用的手段，决定自己能不能像他一样活下来、并且活出头。**

现有实现（`docs/FANG_YUAN_PLAN.md`、`src/game/fang-content.ts`）是一条「按原著顺序走完十四段剧情」的线性流程：每个节点必须完成，玩家只能在两个既定选项里挑一个，结果基本固定。它是一部「带资源记账的视觉小说」。

本次转向后，它应当是一部**生存沙盒**：世界有自己的规则、威胁和时间表；玩家自由安排每天做什么；原著主线只是众多可行路线中收益最高、风险也最大的那一条。判定标准从「你有没有走完流程」变成「**你有没有活下来，并且拿到足以应付下一波威胁的本钱**」。

## 一、核心循环

### 1. 日循环（每次「结束当日」）
1. **观察**：地图事件、威胁指示（狼情、家族风向、仇敌动向、传闻）。
2. **决策**：去哪、做什么——修炼 / 筹备 / 探索 / 交际 / 冒险。
3. **代价**：消耗行动（每日 3 次）、真元、元石、生命；改变隐蔽、疑心、关系、情报。
4. **结算**：结清供养、恢复生命与真元、推进世界时钟。
5. **反馈**：手记落笔、状态变化、新的可选选项出现或消失。

### 2. 成长循环
资源（元石 / 蛊虫 / 材料）→ 修为与蛊虫 → 更强战力与更多选项 → 更高收益，同时招来更大威胁。

### 3. 危机循环
威胁积累（疑心、仇敌、兽潮、仇杀）→ 触发危机事件 → 应对（战 / 逃 / 隐 / 借势 / 出卖）→ 结果（死 / 伤 / 成长 / 破局）。

### 4. 世界时钟（贯穿一切的压力）
世界不会等玩家。若干固定节点会到点发生，玩家必须在它们到来前攒够本钱：

| 节点 | 大致时间 | 含义 |
| --- | --- | --- |
| 开窍大典 | 春（开局后不久） | 空窍开启，修行正式开始 |
| 商队到来 | 春 / 夏 | 唯一的外来购买、销赃、赌石窗口 |
| 年末考核 | 冬 | 学堂毕业、分家、小组编制 |
| 兽潮 / 狼潮 | 来年 | 青茅山存亡级威胁，大量蛊师死亡 |
| 白凝冰自爆 | 约三年后 | 三寨尽灭、青茅山化为绝死冰域 |
| 铁血冷到访 | 两三年后 | 神捕追查旧案 |
| 王大复仇 | 年中考核前后 | 魔道蛊师寻仇 |

**这是本作最重要的一处设计：时间是敌人。** 玩家可以苟，但苟到最后会被狼潮和白凝冰抹平；也可以冒险抢进度，但冒险本身就是死因。

## 二、玩家身份与胜负判定

### 固定身份
古月方源，十五岁，重生归来，带着前世五百年的记忆。不开自定义出身，不更换主角。**资质固定为丙等、元海四成四（44%）**——这是本作的核心难度来源，也是原著事实。

### 三层目标（不是三条互斥结局，而是层层递进的判定）
1. **活着（底线）**：不在任何一次危机中死亡。死亡是真实、可达、且常见的结局。
2. **变强（过程）**：在威胁到来前，把修为、蛊虫、资源、靠山推进到足以自保的程度。
3. **破局（上限）**：拿到原著级别的机缘（花酒传承、血湖、天元宝莲……），成为能左右青茅山格局的人，或在毁灭前离开。

### 失败条件（全部真实可达）
- **战死**：战斗、兽潮、仇杀中生命归零。
- **被处决**：疑心 / 罪行积累到家族刑堂介入，且无靠山可保。
- **被暗杀**：得罪的势力（漠脉、赤练、药姬、外寨、王大）派出的杀手。
- **错失窗口**：狼潮或白凝冰到来时毫无准备，随山寨一同覆灭。
- **困死**：资源耗尽、蛊虫饿死、修为停滞，最终在某个危机里无力应对。

### 生存判定示例（结算页）
结算不写「你通关了」，而写清三件事：**你活到了哪个节点、你手里剩下什么、你离下一波威胁还差多少。**

## 三、世界规则（可玩化，尽量贴原著）

### 资质与真元
- 资质分丁 / 丙 / 乙 / 甲，甲等之上另有「十绝体」（本作远期内容，白凝冰即北冥冰魄体）。
- 资质决定**空窍真元上限**（丙等约 4 成~5 成 9；方源为 4 成 4）与**真元恢复速度**。
- 真元按境界变色：一转青铜（翠绿→苍绿→深绿→墨绿），二转赤铁（浅红→绯红→深红→暗红），三转白银……**颜色越深越耐用**，同一只蛊的催动消耗按真元浓度折算。
- **资质是硬约束**：这是方源一切策略的起点。他必须靠元石、酒虫、舍利蛊、人兽葬生蛊等「歪门邪道」来弥补资质。

### 境界与突破
- 九转制，每转分初阶 / 中阶 / 高阶 / 巅峰。
- 小境界靠温养窍壁（水磨工夫）；大境界（一转→二转→三转）是关卡，需要爆发力冲垮窍壁。
- 方源 4 成 4 的真元，**常规方法冲不过二转**（需 5 成 5）。他必须走非常规路线：
  - 借酒虫精炼真元（提高一个小境界的质量）；
  - 用赤铁舍利蛊硬提一个小境界；
  - 用石窍蛊榨干潜力瞬间到巅峰（代价：断了晋升之路）；
  - 用人兽葬生蛊强行破三转（代价：黑红异种真元、需净水蛊清洗）。
- **这些「偏方」应作为玩家可发现、可选择、可付出代价的路线，而不是既定剧情。**

### 蛊虫：炼、养、用、合炼
- **炼**：炼化野生蛊需压服其意志；春秋蝉气息可秒炼低转蛊（方源专属优势）。
- **养**：每只蛊有特定食物与供养成本，供养不上会休眠甚至饿死。**养不起是方源的真实困境**（原著「养蛊就像养情妇」）。
- **用**：每只蛊只有一个能力；一转蛊数量不限但通常只养得起四五只。
- **合炼**：不同蛊可合成更高级蛊，有秘方、有成功率、失败会损耗甚至死蛊。本命蛊合炼失败不死（重要保护）。
- 蛊虫是**方源战力的主要来源**，也是**最大的开销**。玩家要在「多养蛊（强但贵）」和「少养蛊（穷但活得下去）」之间取舍。

### 元石与供养
- 元石是硬通货，可汲取真元、催动蛊虫、购买一切。
- 每日供养按携带的蛊结算；缺钱则蛊休眠（沿用现有 `getUpkeep` / `hungry` 机制）。
- 元石来源：勒索同窗、家族补贴、任务报酬、卖生机叶、赌石、销赃、战功……**每一条来源都带风险或代价**。

### 时间与季节
- 用「行动日 + 季节」表示。春夏秋冬各有专属事件（商队春来、狼潮夏秋最烈、年末考核冬）。
- 现有实现把方源篇日数上限设成 10000（近乎无限），**这一条必须改**：需要真实的时间压力。

## 四、威胁系统

威胁不是背景板，而是会主动找上门、并按玩家行为升级的实体。

| 威胁 | 触发 / 升级条件 | 表现 | 应对方式 |
| --- | --- | --- | --- |
| **狼潮 / 兽潮** | 世界时钟到点；玩家无法阻止 | 大量电狼、豪电狼、狂电狼、雷冠头狼冲击山寨 | 变强、囤生机叶、借战功换蛊、必要时躲 |
| **家族政治** | 疑心升高、拒绝入体制、树大招风 | 学堂家老打压、药姬夺蛊、被招揽或被孤立 | 保持低调、找靠山（赤练）、进入体制、或强到无人能动 |
| **外寨** | 三寨联盟前后的摩擦 | 斗蛊、暗杀、狼潮中的利益分配 | 结盟、借势、避战 |
| **王大式魔道蛊师** | 玩家杀了有背景的人 | 二转魔道杀手暗中寻仇 | 逃、藏、反杀、借家族之力 |
| **白凝冰** | 世界时钟（约三年） | 青茅山毁灭级灾难 | 提前离开、或强到能自保 |
| **铁血冷 / 神捕** | 玩家留下命案 | 五转神捕追查 | 灭迹、嫁祸、远走 |
| **被反噬的秘密** | 春秋蝉 / 四味酒虫 / 遗藏暴露 | 全族震动、族长翻脸强夺 | 绝不暴露、准备好说辞、或强到守得住 |

**设计原则：威胁的强度随玩家的「张扬度」和「时间」上升。** 越低调越安全，但越低调越难成长——这就是方源处境的张力。

## 五、方源的四张底牌（玩家工具箱）

原著里方源能活下来，靠的不是运气，是四样东西。它们应当成为玩家可调用的核心机制：

1. **记忆（情报优势）**
   - 玩家知道一些未来（赌石有癞土蛤蟆、狼潮要来、某处有传承）。
   - 但记忆会因蝴蝶效应失效——**玩家的改变本身会污染记忆**。这是原著反复强调的主题，应做成机制：玩家改动越大，后续记忆提示越少/越不准。

2. **隐蔽（低调）**
   - 疑心、名声、被关注度是可管理的资源。低调能避祸，但限制收益。

3. **无情（可用的狠）**
   - 玩家可以选择杀人、出卖、勒索、嫁祸。**这些不是道德选项，是生存工具**，但每用一次都会累积仇敌与风险。
   - 家族「血浓于水」的规矩既是保护也是枷锁：杀凡人无所谓，杀族人会引来刑堂。

4. **经验（战斗与谈判）**
   - 五百年的战斗经验 = 战斗中的先手/看破（现有战斗系统的「预判下一招」可以强化）。
   - 处世经验 = 谈判、识人、布局中的额外选项。

## 六、事件系统设计

把现有「线性主线 + 两选一」改成**开放事件图**。

### 事件分类
- **主线机遇（canon）**：花酒遗藏、初炼、报验……收益最高，但门槛高、风险大、可能错过。**不是必经。**
- **支线（side）**：家族任务、小组活动、委托、人际关系。
- **日常（daily）**：修炼、劳作、采药、狩猎——兜底的经济与成长。
- **危机（crisis）**：由威胁系统触发，往往无法回避，只能应对。
- **世界事件（world）**：商队、开窍大典、狼潮、斗蛊大会——到点发生，影响全局。

### 开放条件（替代现有的「前置旗标」硬门）
事件可用性由多种条件共同决定：
- 时间 / 季节 / 日期窗口；
- 剧情旗标（保留，但只用于真正的因果依赖）；
- 境界、修为、持有蛊虫、资源；
- 关系、疑心、名声；
- 世界状态（狼潮是否爆发、商队是否在、某人物是否还活着）。

### 抉择后果（要真正分叉）
- 资源得失、生命真元；
- 关系与疑心；
- **旗标 + 世界状态**（例如：杀了王大 → 触发复仇线；放过他 → 未来少一个敌人但多一个隐患）；
- 有些选项**永久关闭**别的选项（错过商队就买不到某蛊）；
- 有些选项**引入新威胁**（暴露秘密、结仇、引来神捕）。

### 关键改造点
现有 `stepEvent()`（`src/game/fang-content.ts`）强制每个事件依赖前一个 flag、且完成后不可重来。新系统需要：
- 允许**并行**的多条线（同时进行学堂线、遗藏线、家产线、狼潮线）；
- 允许**可选/跳过**的主线节点；
- 允许**失败或放弃**不导致死锁；
- 允许**世界事件**不依赖玩家 flag 也能触发。

## 七、青茅山篇分幕（与原著对照）

以下是本作长期要覆盖的「青茅山篇」全貌。**近期只做前两幕的沙盒化**，后几幕作为路线图。

### 第一幕 · 重生开窍（原著 1–8 节）——**已有雏形，需沙盒化**
- 夜雨重生 → 开窍大典（二十七步、丙等四成四）→ 领月光蛊 → 家宅交涉（拒过继、拒提前分家）。
- **改造**：家宅交涉不再只有两个选项，而是可以周旋、拖延、试探舅父舅母；开窍结果固定但玩家可决定如何应对众人目光。

### 第二幕 · 学堂与初炼（原著 9–38 节）——**现有实现覆盖到 20 节**
- 雨中炼蛊 → 客栈避人 → 青竹酒 → 诱虫 → 花酒石洞（酒虫、影壁真相）→ 初炼酒虫反噬 → 春秋蝉显形 → 月光报验夺头名 → 勒索同窗 → 高碗之死 → 碎尸送礼。
- **改造重点**：
  - 报验之后不结束，而是**继续**；
  - 勒索同窗做成**可重复的高风险经济行为**（得罪全体同窗、累积名声）；
  - 高碗之死做成**玩家可选**的冲突（可以忍、可以杀、可以逃），杀了之后**碎尸送礼**是一个高明的自保选项（原著核心智慧）；
  - 春秋蝉显形是**玩家必须自己发现的秘密**，不是自动剧情。

### 第三幕 · 学堂修行与赌石（原著 39–59 节）
- 商队到来 → 赌石开出癞土蛤蟆（可卖 500 元石）→ 猴儿酒主动暴露酒虫 → 把影壁卖给贾金生（2000 元石）→ 杀贾金生 → 应对贾富对质（竹君子测谎、祸水东引）→ 四味酒虫准备 → 年末考核（擂台战、二转）。
- **这是方源第一次真正的「以智破局」**，应做成高自由度的博弈关卡：玩家可以选择卖不卖影壁、杀不杀贾金生、怎么应对对质。

### 第四幕 · 家族任务与石林传承（原著 60–116 节）
- 分家、继承遗产（九叶生机草、酒肆、竹楼）→ 地下石林传承（白豕蛊、玉皮蛊、地听肉耳草）→ 兽潮 → 吞江蟾（五转蛊，力士推蟾）→ 四味酒虫 → 隐鳞蛊 → 三步芳草蛊 → 斩杀石猴王。
- **这是资源管理与探索的黄金段**：石林是可以反复进入的「副本」，石猴是经验与材料来源。

### 第五幕 · 狼潮与白凝冰（原著 117–154 节）
- 狼潮爆发 → 三寨联盟、斗蛊大会 → 追杀白凝冰 → 古月青书之死 → 晋升三转 → 与药姬、赤练的政治博弈。
- **这是本作的第一个「存亡级」高潮**：大量蛊师死亡，方源必须在混乱中做选择——救人、自保、还是趁火打劫。

### 第六幕 · 血湖与再次重生（原著 155–199 节）
- 血湖墓地、铁血冷 vs 古月一代、天元宝莲、三族大比、白凝冰自爆、**再次重生**。
- **「再次重生」是本作的终极机制出口**：如果玩家在这一世失败（死亡），春秋蝉可以（有代价地）重启——但要满足条件（春秋蝉恢复度、修为、时机）。这既是原著的收束，也是 roguelike 式的循环设计。

## 八、与现有实现的差异及改造清单

### 保留（架构是好的）
- 纯函数引擎 `gameReducer`、按 campaign 选择的 selector（`src/game/campaign.ts`）、存档校验（`src/game/storage.ts`）——**继续用**。
- 资源 / 状态 / 供养 / 战斗 / 合炼系统——**作为基础**。
- 新旧篇章隔离（`campaign: 'fang-yuan'`）——**继续用**。

### 必须改
| 项 | 现状 | 目标 |
| --- | --- | --- |
| 主线结构 | `FANG_STEPS` 十四段线性、强前置依赖 | 开放事件图，支持并行/可选/失败 |
| 结局 | 只有 `fy-first-gu` 一个成功终点 | 死亡 / 存活 / 破局多层判定，多个终点 |
| 时间 | 方源篇日数上限 10000，几乎无限 | 真实时间压力 + 季节 + 世界时钟 |
| 威胁 | 无 | 狼潮、政治、仇敌、白凝冰等主动威胁 |
| 记忆 | 无 | 「记忆」作为会随蝴蝶效应衰减的情报资源 |
| 抉择 | 每节点两选一，结果固定 | 多选项、真分叉、永久后果 |
| 战斗 | 保留但方源篇 `FANG_ENEMIES = []` | 接入真实敌人（狼、蛊师、兽王） |
| 蛊虫 | 只有月光、酒虫两只 | 扩展到石林/商队/血湖的完整蛊表 |

## 十、验收标准（设计层面）

1. 玩家可以在不完成花酒遗藏的情况下活到某个节点——且这条路线有独立的价值与代价。
2. 死亡是常见且可解释的：每次死亡都能指出是哪个威胁、哪个选择导致的。
3. 原著主线是「最优解之一」，不是「唯一解」；走原著路线需要玩家自己发现并承担风险。
4. 时间是真实压力：苟到底会被狼潮 / 白凝冰抹平。
5. 玩家能感受到「像方源那样」的处境：资质差、资源紧、威胁多、必须靠记忆与狠劲破局。
