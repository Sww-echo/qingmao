## 核心决策

- 桌面优先，首轮实测 macOS；GDScript + Compatibility，尽早验证 Web。精确引擎版本和同版模板在环境验证时锁定。
- `godot/` 并行工程；纯规则、会话、存储、场景四层；唯一权威状态由 `GameSession` 持有，UI 只能提交动作和读取投影。
- 先忠实移植已冻结 V1，证明 RNG/逐步状态一致；再在 Godot 推进 V2 节奏改造，保留 V1 夹具，不长期双写两套规则。
- 先交付 **可见的原生启动窗口和中文地点场景**，再交付可玩的第 1 日，最后交付完整 14 日。每次演示标明属于哪一阶段。
- 新试玩独立存档；旧 Web 和旧 v2 存档保留。首版没有自动旧档转换。
