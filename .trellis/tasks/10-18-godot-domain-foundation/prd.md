# P2 Godot 基础：数据、规则与存档

> 2026-10-19 · in_progress · W0/W1/W2 已完成；W3 自动门槛已验证，待 P2 交接评审。继承父 PRD R6 和平台/兼容约束。

## 目标

建立可独立运行、可验证的 Godot 规则底座，使后续场景不再重复实现规则。

## 前置

P1 提供冻结规则、内容版本、事件图与合法动作参考轨迹；最新 [实现重设计](../10-18-godot-impl-redesign/README.md) 已于 2026-10-18 获用户批准（“先提交再按任务开始实施”）。W1–W3 以该方案为执行依据，保留已交付 W0。

## 范围

- 并行 Godot 4 工程，桌面优先并验证 Web 路径。
- 首版数据加载、操作、查询、随机数和 GameSession。
- 同规则版本跨引擎状态对照。
- 独立存档、严格校验、备份恢复和旧格式拒绝。
