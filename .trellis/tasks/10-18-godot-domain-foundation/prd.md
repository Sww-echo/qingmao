# P2 Godot 基础：数据、规则与存档

> 2026-10-18 · planning · 继承父 PRD R6 和平台/兼容约束。

## 目标

建立可独立运行、可验证的 Godot 规则底座，使后续场景不再重复实现规则。

## 前置

P1 提供冻结规则、内容版本、事件图与合法动作参考轨迹；最新 [详细架构方案](../10-18-godot-architecture-plan/README.md) 已评审后才开工。P1历史授权不自动满足本次更新后的评审门槛。

## 范围

- 并行 Godot 4 工程，桌面优先并验证 Web 路径。
- 首版数据加载、操作、查询、随机数和 GameSession。
- 同规则版本跨引擎状态对照。
- 独立存档、严格校验、备份恢复和旧格式拒绝。

## 验收

| ID | 结果 | 父标准 |
| --- | --- | --- |
| P2-A | 首个真实Godot窗口可见，中文、角色移动与目标交互可操作；版本/模板/路径及最小导出结果齐全 | AC1 前置 |
| P2-B | RNG向量、三黄金轨迹及V1全600局逐步完整State一致（含日志/账本）；拒绝无副作用 | AC6 |
| P2-C | 坏档、旧档、事件/战斗/日结恢复行为正确 | AC5、AC7、AC8 |
| P2-D | Web 最小导出有实际结果或明确可复现阻断 | AC10 |
| P2-E | 后续场景可通过冻结会话接口取得状态和提交动作 | AC1 前置 |

不包含完整场景美术、全旧篇移植、旧档自动转换或公众发行。
