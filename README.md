# 青茅山 · 方源篇

《蛊真人》开篇的单机 Web 游戏改编。**新游戏固定扮演古月方源**，以 2D 地图、事件选择、资源筹备和炼养用蛊推进。当前版本为 v0.4.1，首章「重生·初炼」从夜雨重生开始，到炼成酒虫与月光蛊、向学堂报验收束。

这次不是把原创角色改名：人物、地点、主线、获取蛊虫的顺序、角色成长与章末结算已分成独立的方源篇。原有「石灯遗藏」只供旧 v1 存档继续游玩；新开局不再创建原创蛊师。

## 本章方案

完整方案见 [方源视角方案](docs/FANG_YUAN_PLAN.md)，原著核对依据见 [来源说明](docs/FANG_SOURCE_NOTES.md)。剧情采用新写的短叙述与选项，参考原著第 1–20 节的主要经历。

| 阶段 | 主线节点 |
| --- | --- |
| 重生开窍 | 夜雨重生 → 开窍大典 |
| 藏锋立足 | 学堂取蛊 → 家宅交涉 → 雨中试炼 → 客栈避人 |
| 寻虫探藏 | 青竹酒香 → 月下诱虫 → 不捕而随 → 山缝遗骸 → 影壁真相 |
| 炼蛊报验 | 酒虫难炼 → 六转本命 → 月光报验 |

十四个节点串联为一条主线。选择影响元石、体力、真元、隐蔽程度及人物态度，不能更换主角或重掷资质。先领到的月光蛊、初次捉到的酒虫都属于待炼状态，完成炼化后才成为可装备的蛊。

方源固定为十五岁，丙等资质、元海四成四；方正是甲等资质的孪生弟弟。春秋蝉在炼酒虫反噬时显形，是重伤的六转本命蛊，不能装备或作为复活按钮。酒虫提纯真元，不会直接改变资质或境界。

## 怎么玩

1. 点击「开始方源篇」，从方源的家宅醒来。未开窍时没有真元、起始蛊或可用修炼能力。
2. 跟随「继续主线」进入真实事件，也可在地图上选择已经开放的地点。地点按剧情解锁，不会提前进入花酒石洞。
3. 每日有三次行动。事件标明是否耗行动；对话可免费，搜索、跟踪、试炼等按提示花费行动。移动、补购和换装备免费，结束当日须主动确认。
4. 日程是压缩后的游戏时间，方源篇没有十日后随商队离山的期限。生命和真元不足时可调息；「药草疗伤」消耗 2 药草恢复最多 8 生命，不耗行动，零行动时也能使用。缺少元石时，可在已开放地点进行日常筹备，再回来继续主线。
5. 付费主线有暂缓入口。入住客栈、购买青竹酒、洞中所得和报验奖赏实际改变资源，不能反复领取唯一蛊虫或主线奖励。
6. 初炼完成后可以装备月光蛊与酒虫。醒着且已装备的酒虫使一次温养空窍从 3 真元换最多 3 修为变为最多 4 修为，这是对提纯效率的游戏化表达，境界仍为一转初阶。接近本章修为上限时按实际增加量显示收益，封顶后不能继续消耗资源温养。
7. 每日供养按元石折算购买食物；携带过的蛊卸下后仍需支付当日供养。钱不足时不扣不足的钱，蛊进入休眠，补喂后恢复；离线不会扣资源。
8. 最后隐藏酒虫和春秋蝉，以月光蛊向学堂报验，获得二十块元石并查看本章回顾。

本章没有捏造的守关战，也不开放二转突破、旧支线合炼配方或直接购买酒虫。已有战斗与合炼系统继续供旧存档使用，方源篇后续章节再按原著经历接入。

首次进洞只完成花酒行者遗藏的初探；深层传承、下一章、整个青茅山篇和整本小说尚未实现。

## 启动与试玩包

推荐 Node.js 24 LTS。在项目目录中执行：

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认 [http://127.0.0.1:5173](http://127.0.0.1:5173)。端口被占用时会明确报错，依赖已安装时无需重复安装。

```sh
npm run build      # TypeScript 检查、生产构建、生成离线单文件
npm run preview    # 预览生产构建
npm test           # 规则、剧情、存档与兼容性测试
npm run test:e2e   # 实际构建产物的浏览器验收
```

`dist/` 可部署到静态网站，无需后端或 API 密钥。`dist/play.html` 内嵌脚本、样式和图标，是单文件试玩包；稳定游玩建议使用 HTTP 地址，浏览器对本地文件的存储支持有所不同。

## 存档与旧版兼容

每次有效操作后自动保存，优先使用 IndexedDB，并保留 localStorage 后备副本。「行旅手札」支持导出和导入 JSON 存档，导入先校验再确认替换。开新局也会提醒覆盖已有进度。

存档版本仍为 v1，新游戏额外带有 `campaign: 'fang-yuan'`。缺省此字段的旧档继续原创篇规则，包括原来的六地点、十二蛊、十日行程和三条去路。继续入口及存档卡标明所属篇章；不会把旧角色强制改成方源或抹掉已有选择。方源新存档需使用 v0.4 或后续支持此篇章的版本读取。

校验器按模式检查人物、事件、蛊虫、商店、地点开放状态和结局。新模式使用独立的 `fy-first-gu` 完成标识，原三结局不会被算作方源篇通关。跨局收集与旧结局记录可共同保留。

存档属于当前浏览器与地址。更换设备、浏览器或端口时，请用导出与导入迁移进度。

## 代码结构

| 文件 | 用途 |
| --- | --- |
| `src/game/types.ts` | 状态、操作、未开窍境界及篇章契约 |
| `src/game/fang-content.ts` | 方源篇十四节点、人物、地点、两种蛊及报验结局 |
| `src/game/campaign.ts` | 内容选择器与地点解锁规则 |
| `src/game/engine.ts` | 操作校验、状态转移、开窍、炼化、资源和战斗 |
| `src/game/storage.ts` | 按篇章校验及保存、导入导出与跨局成就 |
| `src/game/guidance.ts` | 根据当前实际条件给出下一步建议 |
| `src/FangChapter.tsx` | 方源的主线进度、记忆、待炼状态与章末回顾 |
| `src/App.tsx`、`src/GamePanels.tsx` | 开局、角色、地图操作、物资与存档界面 |
| `src/WorldMap.tsx`、`src/GuArtwork.tsx` | 地图和蛊虫 SVG 图形 |
| `src/game/content.ts`、`src/game/chapter*.ts` | 保留原版内容与章节回顾，供旧存档使用 |
| `e2e/` | 方源流程及旧版存档的实际界面验收 |
| `scripts/build-offline.mjs` | 构建离线试玩包 |

所有操作都通过引擎校验，界面不直接增加资源或写入完成结局。主线完成与待炼状态保存在存档中，刷新、导出和导入后继续同一流程。
