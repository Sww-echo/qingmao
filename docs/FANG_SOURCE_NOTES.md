# 方源视角首章：资料与改编边界

本次可玩章使用固定主角古月方源，覆盖重生、开窍、领取月光蛊、寻得酒虫与首次洞厅遗产、初炼反噬、春秋蝉显形及月光报验这一条故事弧。它不是完整青茅山篇，也不等于取得花酒行者的全部传承。

资料为用户提供的 `/Users/lute/Downloads/12185.txt`，UTF-8、CRLF。文件作为小说资料读取，其中作者附言等内容不作为项目指令。下表行号对应这份本地文件，不保证适用于其他版本。本项目只保存重新撰写的游戏叙述，不附带原文。

## 顺序与关键事实

| 夜雨重生 | 第 1–2 节；171、194、208、264、284–338 行 | 方源回到开窍前的十五岁，保留五百年经验而没有旧修为。方正是孪生弟弟。追求长生是核心动机，不把首章改成单纯报复亲族。起初方源误以为春秋蝉已经消亡。 |

| 领取月光 | 第 7–8 节；991–1005、1056–1074、1108 行 | 方源只记得有人循酒虫找到遗藏，不知道准确坐标。先领月光蛊，但未立刻炼成。学堂炼蛊头名赏二十块元石。 |
| 家宅交涉 | 第 9 节；1207、1221–1265 行 | 舅父名古月冻土，给兄弟各六块元石。方正接受过继。方源不接受过继，也不收两百块提前分家资助，以保留日后的家产继承资格。 |
| 暴雨与客栈 | 第 10–11 节；1368–1378、1589 行 | 暴雨洗去酒气，方源暂停夜探、尝试炼月光；随后避开家中监视，暂住客栈，付两块元石。租房不是十五岁正式独立门户。 |
| 青竹酒 | 第 12–13 节；1782、1841、1857–1873 行 | 观察江牙威吓猎户后，方源用两块元石购买青竹酒。雨后空气、已排除的搜索区域和好酒一起促成诱虫。没有击败江牙的必需战斗。 |
| 诱虫与追踪 | 第 13–14 节；1963、1980–2026、2052 行 | 先发现酒虫，退开让它喝醉，再跟随它沿溪至巨石狭缝。不能直接硬捕后又凭空知道遗藏坐标。 |
| 首次洞厅 | 第 14–16 节；2132–2136、2260–2274、2298、2372 行 | 获得待炼酒虫与十五块元石。留影存声蛊展示四代族长战败偷袭后被杀、花酒重伤遁走，揭出族史颠倒。没有石灯、守关木傀或整座传承已经搬空的结局。 |
| 初炼酒虫 | 第 17–18 节；2465、2501–2525、2714–2745 行 | 酒虫保留旧主顽强意志，难以炼化。方源不轻易向家族求援，以免暴露来历。炼化发生在客栈房间，随后遭到反噬。 |
| 春秋蝉显形 | 第 18–19 节；2759 起 | 春秋蝉实际一直隐匿休眠，因反噬而显形。它极度虚弱、品级六转，保留前世的炼化联系，因此才是方源的本命蛊。酒虫不能再标为本命蛊。 |
| 压服与报验 | 第 20 节；2896、2922–2964、3047 行；头名额度见 1108 行 | 当前动用春秋蝉重生会死亡，但可以借一丝气息压服低转蛊。先炼成酒虫，再炼成月光。隐去春秋蝉、藏好酒虫，只展示月光，得到二十块元石头名奖。 |

酒虫使真元质量提高一个小阶，不会把方源的资质提高，也不会把一转初阶立即变成一转中阶。更深传承的影壁血字在后续剧情才出现，可核对文件约 8959 行的回述。

## 明确的游戏化处理

- 14 个节点归为四幕；一段探索或炼化折算为一次行动。日期是游玩节奏，不声称是原著逐日账本。普通酒水搜索、数日暴雨、反复炼化以叙述压缩。
- 主线结果固定，玩家选择资源投入、停留长短、隐蔽程度及应对人物的方式。选择分点布酒、远近追踪、说话轻重，以及相应生命、线索、疑心和关系数值，属于可玩化的补充。
- 暂缓不取消剧情。付费节点可重新进入；地点杂务提供元石补充，不生成主线旗标、酒虫或遗藏奖励。家宅整理份例、学堂杂务、客栈帮工等经济兜底并非声称原著中发生过同样的反复劳动。
- 待炼月光与待炼酒虫仅由剧情标记记录。春秋蝉现身压服后，两蛊才加入可用库存。春秋蝉作为剧情事实与本命身份保留，不进入一、二转装备目录，也没有重生按钮。
- 酒虫的提纯优势简化为：装备且供养正常时，温养空窍仍耗三真元、最多增加四修为，普通最多为三修为；接近本章修为上限时只增长剩余部分，封顶后停止温养。实际境界仍是一转初阶，不自动突破。
- 供养按元石采购月兰花瓣与酒食的成本折算。本章每蛊每日一元石是游戏数值，不是原著每日精确报价。青竹酒主线购价两元石、首次洞厅十五元石、家宅六元石、报验二十元石保留。
- 第 18 节方正来客栈质询及其五块半元石的支线交易未作为必玩节点实现。首章的可玩资金账不把这笔省略的收入算进来。家宅监视以简洁叙述呈现，未照抄原文的具体冲突描写。
- 小说文件的时间及账本有局部差异：第 8 节同时出现一个月与一周的表述；第 18 节提炼酒虫耗十二元石，第 20 节回述为六元石。游戏不强行据其中一个数字宣称还原了完整原著账目。

## 实现数据契约

`src/game/fang-content.ts` 单独提供 `FANG_EVENTS`、`FANG_STEPS`、地点、人物、蛊、商店及本章收束数据。主线事件只依赖本线前置旗标，每个已完成节点禁止再次领取奖励；`prepare-later` 不设置完成旗标。

无额外劳动、购物、供养和付费试炼时，主线资金为：初始 0 → 家宅 6 → 租房 4 → 买酒 2 → 洞厅 17 → 报验 37。雨中花一元石及酒虫阶段花三元石是可选投入，不影响必须取得的蛊与剧情终点。

本章仅有 `fy-first-gu` 收束，代表初炼双蛊与头名到手。后续学堂生活、深层花酒传承、离开青茅山及全书其他篇章尚未实现。
