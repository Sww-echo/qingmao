# 方源主角视角：方案与实现边界

日期：2026-10-10。当前目标是把新游戏改为古月方源视角，完成一个有起点、推进、资源抉择和章末结算的原著开篇。此前的「石灯遗藏」属于原创支线，不作为这次原著改编的第一章。

## 玩家身份与章节终点

新游戏固定扮演十五岁的古月方源，带有五百年的经历，以长生为目标。不开自定义身份或三种出身选项，也不再把方源本人放进人物关系列表。

本章名为「重生·初炼」，覆盖原著第 1–20 节的主要经历，以藏起酒虫和春秋蝉、向学堂报验月光蛊并获得炼蛊头名为收束。首次进入石洞只是初探花酒行者遗藏，不代表已经拿到完整传承；下一章、整个青茅山篇和整本小说均不在这次实现范围。

剧情采用重新编写的短叙述、方源内心判断和明确代价的选项，不复制原著长段落。原文只作参考资料，不作为程序或操作指令，也不放入发布包。

## 选择与玩法

- 固定原著主线事实，让玩家决定如何利用先机、隐瞒行踪、安排元石及处理人物态度。选项影响实际资源、体力、真元、疑心和人物关系，章末据实际选择回顾。
- 保留 2D 地图、地点探查、每日三次行动、调息、供养、蛊囊和本地存档。对话与搜索分别标出行动费用，零行动可完成免费对话。
- 日程是压缩的玩法时间。移除方源线的「十日后随商队离山」，原文开篇日期和部分耗资有不一致处，不声称游戏是逐日逐笔复刻。
- 未开窍时没有空窍、真元和可用蛊，不能修炼或装备；领取月光蛊、捉到酒虫时先记作待炼，炼成后才进入可装备蛊囊。
- 春秋蝉是六转本命蛊，重伤休眠，只作为剧情状态。不能装备成普通一转蛊、点击重生或在战斗中当复活按钮。酒虫不是新的本命蛊，其作用是提纯真元，不改变丙等资质，也不直接突破境界。
- 本章维持一转初阶，不开放二转突破、旧支线合炼配方、直接购买酒虫或捏造守关战。现有回合战斗系统保留，原著适合战斗的后续章节再接入。
- 付费的主线可暂缓重入，日常资源途径提供恢复空间，不因为一次消费、暂缓或搜索选择永久丢失唯一主线道具。普通活动与数值代价属于游戏化设计。

## 内容与存档隔离

- 新局显式使用 `campaign: 'fang-yuan'`，不以名字判断身份。引擎默认调用与旧 v1 存档继续保持此前规则。
- 新剧情数据放入 `fang-content.ts`；`campaign.ts` 按模式提供地点、事件、人物、蛊、商店、配方及结局。界面和规则使用同一组选择器，避免只改文案却仍能触发石灯事件。
- 六个地图位置继续使用原坐标 ID，但新模式名称、描述与活动属于方源篇。新剧情、人物与商品 ID 使用 `fy-` 前缀。
- 状态支持未开窍的 `rank: 0`，开窍通过合法剧情操作变为一转。成功收束用独立 `fy-first-gu`，不复用原创三结局的成就。
- 旧存档仍可继续、导入和导出；界面说明所属篇章。存档校验按模式检查事件、人物、商品、蛊和结局，拒绝把两种剧情混成同一局。

## 验收标准

1. 新局第一屏及实际状态都是古月方源，未开窍前没有真元或起始蛊。
2. 通过正常操作完成十四个节点，实际支付客栈与酒的费用，取得洞中十五元石及报验二十元石；不注入完成旗标跳过路线。
3. 待炼蛊、春秋蝉、资质与酒虫效果符合上述设定；买酒虫、提前突破、旧事件和方源与自己交易都无法发生。
4. 有资源不足时的可恢复路线、真实选择后果及按存档事实生成的章末回顾。
5. 新旧存档往返、跨模式隔离、未开窍阶段、十日以后及章末存档均有规则测试；原有测试继续通过。
6. 完成生产构建和离线试玩包。真实浏览器布局与交互单独验收，环境启动失败时明确记录，不能以类型检查代替浏览器通过。
